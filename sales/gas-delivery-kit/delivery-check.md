# 納品前チェック(出品者用)
すべて、ダミーデータで確認する。実データをAIツールに入力していないことを再確認する。
- [ ] 要件(質問票)と、作ったものの範囲が一致している。違う点は購入者に伝えた。
- [ ] 自分のGoogleアカウントで、初回の権限承認から最後まで通した(承認画面の文言は手順書と一致するか)。
- [ ] 正常系: 想定どおりの入力で、想定どおりの出力になる。
- [ ] 異常系: 空欄・全角半角・日付の表記ゆれ・重複・読み取れないデータで、止まらず「要確認」等に残る。
- [ ] 2回続けて実行しても、重複して増えない。
- [ ] 失敗させて、実行ログに残り、通知が届くことを確認した(メールアドレスをテスト用に設定)。
- [ ] 診断シートで「OK」を確認し、シート名を変えると「要対応」になることを確認した。
- [ ] 設定値(メールアドレス・シート名・検索条件)が納品先用に書き換わっている。サンプルの値(example@example.com)が残っていない。
- [ ] 手順書の【 】がすべて埋まっている。事実でないことを書いていない。
- [ ] 実行時間・メール送信数など、GASの上限に近づかない量であることを確認した。
- [ ] 実環境で確認できていない項目は、購入者に正直に伝えた。
