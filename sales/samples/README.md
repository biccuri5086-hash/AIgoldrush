# 受託ポートフォリオ用サンプル(Excel)

すべてダミーデータです(氏名・登録番号T0000000000000・口座は実在しません)。生成: `tools/build.py`、検証: `tools/verify.py`(要 openpyxl と LibreOffice)。

## 1. invoice-template.xlsx(インボイス対応請求書)
- 明細20行、税率(10/8)選択、軽減税率に※表示。
- 税率ごとの税抜合計と消費税額を表示し、消費税は税率ごとに1回だけ計算(端数処理は切捨て/四捨五入/切上げを選択)。整数演算のため浮動小数点誤差なし。
- 源泉徴収スイッチ(する/しない)。税抜合計の100万円以下部分10.21%、超過部分20.42%、1円未満切捨て。
- 登録番号欄(T+13桁の形式チェックのみ)、A4縦1ページ印刷設定、数式セルはロック(パスワードなし)、入力欄は黄色、「使い方」シート付き。

## 2. quote-template.xlsx(見積書)
請求書と同じ計算ロジック。有効期限・件名・納期欄あり。源泉徴収は参考表示。

## 3. expense-tracker.xlsx(月次の売上・経費管理)
「取引」(最大300行、家事按分=事業割合%、按分後は1円未満切捨て)、「年間集計」(月別売上/経費/差引、勘定科目別の計上額・按分除外額、整合チェック)、「使い方」。

## 検証方法(2026-10-09実施)
LibreOffice headless で入力を差し替えたコピーを再計算し、Python整数モデルと全セル比較(`python3 tools/verify.py`)。
- 請求書・見積書 各24ケース(計48)で不一致0。内訳: 10% 100,000円(税10,000)、8% 333円(切捨て26/四捨五入26/切上げ27)、120万円源泉=142,940、100万円ちょうど=102,100、1,000,001円、12,500円x8%の浮動小数点罠、乱数15ケース。
- 家計簿: 月別集計、対象年外の除外、按分(5,555円x50%=2,777、3,333円x33%=1,099)、科目別・整合チェックを確認。
- 既定値のファイルを再計算し、数式エラーなし、登録番号チェック動作、PDF化で請求書が1ページに収まることを確認。

## 限界・未検証
- Excel実機・Googleスプレッドシートでの動作は未確認(LibreOfficeのみ)。openpyxl出力のため計算結果キャッシュはなく、開いた時に再計算される。
- 税率・源泉徴収率・取扱いの一次情報(国税庁等)との再照合は本サンプル作成時に行っていない。公開・納品前にファクトチェックが必要(源泉は報酬の種類により対象外あり、消費税区分記載時に税抜計算可とする取扱いの確認要)。
- 登録番号は形式のみ。実在確認はしない。マイナス明細(値引)は符号対応しているが、検証はプラス値中心。
- シート保護はパスワードなしで誤操作防止用。セキュリティ機能ではない。
- 電子保存要件、複数ページ明細、簡易課税・仕入税額控除の集計は対象外。
