# AI運営組織

| 役割 | 定義ファイル | 担当 |
|---|---|---|
| 編集長 | .claude/agents/editor-in-chief.md | 週次レビュー、優先順位、やめる判断 |
| 開発 | developer.md | ツール実装・検算 |
| ライター | writer.md | 記事・職種別ガイド |
| 批判役兼ファクトチェック | fact-checker.md | 正確性と差別化の検証 |
| マーケ | marketer.md | 集客計画・投稿案 |
| 受託営業 | sales.md | 出品文・提案・見積 |
| 分析 | analyst.md | 数字の記録と判定 |

## 使い方
1. オーナーは週1回、Search Console/AdSense/受託の数字を貼って「週次レビューして」と伝える。
2. 編集長がops/weekly-routine.mdに従い、各担当へ指示して結果をまとめる。
3. オーナーの作業(承認・登録・投稿・支払い)は一覧で渡される。

## AIがやらないこと(オーナーの作業)
お金の支出、アカウント登録、契約、SNS投稿、プラットフォームでの応募・納品の送信、本人確認。
