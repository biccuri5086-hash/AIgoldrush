# 週次レビュー手順
1. analyst: 今週の数字をmetrics.csvに追記(表示回数、クリック、PV、ツール別利用、広告収益、受託の問合せ/受注/売上)。
2. 編集長: kpi.mdの判断ルールで、ツール/記事ごとに「伸ばす・様子見・削除」を決める。
3. fact-checker: 今週公開/変更した物の事実確認。法改正の確認を月1回。
4. developer/writer: 『伸ばす』判定のものだけ強化。新規は当たり候補1つまで。
5. marketer/sales: 今週の投稿案、出品文の改善案。
6. 編集長: ops/decisions.mdに決定を追記し、オーナーへ『今週お願いしたいこと』を最大5件で報告。
