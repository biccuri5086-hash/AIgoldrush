報酬の源泉徴収税額計算

計算方法

原稿料・デザイン料・講演料などの報酬は、1回の支払額が100万円以下なら10.21%、100万円を超える部分は20.42%です。請求書で消費税額が区分されている場合は、税抜金額が源泉徴収の対象です。弁護士・税理士等の報酬や、他の所得区分には別の規定があります。

すべてのツール

税金・請求書
消費税計算(税込⇔税抜) / 報酬の源泉徴収税額計算 / 10%・8%混在の請求書 消費税計算 / インボイス登録・消費税納税額の比較 / 副業の税金(所得税・住民税)の目安 / 手取りから請求額を逆算(源泉徴収あり)

給与・働き方
時給⇔月給・年収の換算 / 残業代(割増賃金)の計算 / 勤務時間・労働時間の計算 / 有給休暇の付与日数計算 / フリーランスの必要時給・単価の計算

事業・経理
割合・割引・増減率の計算 / 利益率・粗利率の計算 / 損益分岐点の計算 / 家賃・光熱費の按分計算 / 減価償却費の計算(定額法)

お金・日付
日割り計算・日数計算 / 西暦⇔和暦変換・年齢計算 / 複利計算・積立シミュレーション / ローン返済シミュレーション

計算結果は目安です。税務・労務・法律上の判断は、税理士・社会保険労務士・税務署などの専門家や公的機関にご確認ください。
