## 3. 判断ルール

### 3-1. 広告予算 ¥50,000 を使う条件(すべて満たす場合のみ)
1. 公開から最低6週間経過し、実測データが3週分以上ある。
2. AdSense承認済み、または収益化(アフィ)の導線が稼働している。
3. 計測が正常(ツール利用イベント、アフィクリックが取れている)。
4. 品質問題がない(重大な計算誤りが未修正でない)。
5. 自然流入の"ツール利用率"が一定以上(例: 目安として利用/セッション ≥ 30%。実測の中央値に合わせて調整)。= 来た人が使える状態。
6. 1セッションあたりの期待収益(RPM+アフィ)が実測できていて、"1セッション獲得費用(CPC/CPA)< 1セッションあたり収益" になる見込みが立つ。
   - 見込みが立たない(獲得費用が収益を上回る)なら使わない。広告は"黒字化"よりも"学習(どのKW/訴求が反応するか)"目的で小額から。

### 3-2. 予算の使い方(段階投入)
- 第1段階 ¥10,000: 検索広告またはX広告で、最もツール利用率が高いページ1〜2つに7〜14日。
- 評価: CPC・ツール利用単価(広告費÷ツール利用数)・アフィクリック率。
- 継続条件: 広告費1円あたりの推定収益(AdSense+アフィ)が実測で1円に近づく/上回る → 追加 ¥20,000。それ以外は停止。
- 最終 ¥20,000: 勝ちパターンのみ。残りは使わず温存してよい("使い切る"ことは目的ではない)。
- 広告文は正確に(「確実に節税」等は禁止)。ランディングはツールページに直接。

### 3-3. 止める(撤退・縮小)基準
- 広告: 第1段階で、ツール利用単価が目標を大きく上回る/アフィクリックがほぼ0 → 全停止。
- SNS: 同一フォーマットを4週続けて反応が極小なら、フォーマットを変える。8週で成果ゼロの媒体はやめる。
- ツール追加: Search Consoleのクエリ需要がないものは作らない。
- サイト全体(Day 90評価):
  - 継続: セッション/表示回数が増加傾向 or 収益がコスト以上。
  - ピボット: 表示は出るがクリックが低い → タイトル/ディスクリプション改善、別KW。
  - 縮小(最小運用): 90日で表示回数がほぼ増えず、収益がコスト未満 → 新規投資を止め、固定費(ドメイン代程度)のみで放置運用。Q1(確定申告期)のみ集中して再挑戦。
  - 撤退: 6か月で進展が見えず、固定費も回収できない場合に検討。

### 3-4. アラート(即対応)
- 計算誤りの報告 → 当日調査、修正、更新履歴に記載。
- Search Consoleの手動対策/セキュリティ問題 → 最優先。
- AdSenseポリシー警告 → 該当箇所を即修正。無効クリックの疑いが出たら配置見直し。
- 税制改正 → 該当ツール・記事を更新。

3. コスト・収益・損益。
