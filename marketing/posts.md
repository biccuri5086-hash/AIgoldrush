# 投稿ドラフト集(約40本)

使い方
- `[URL]` は実際のURLに置換。`[運営者]` は自分の名前/ハンドルに。
- 数値・税率は投稿前に国税庁の最新ページで確認。税制は改正される。
- アフィリエイトリンクを含む投稿は先頭に「PR」を入れる(affiliate.md 参照)。本ファイルのA系以外は広告を含まない。
- 同じ文面の連投・複数アカウントでの拡散は禁止。1日に宣伝色のある投稿は最大1。
- 実績(PV・収益など)は、実際の数字が出てから事実のみを書く。下記の「◯」は実数に置換し、未達なら投稿しない。

**X-02 豆知識: 源泉の税率**
報酬の源泉徴収、税率は支払額で変わります。
・100万円以下の部分: 10.21%
・100万円を超える部分: 20.42%
(復興特別所得税込み。対象になる報酬は限られます)

**X-03 消費税の端数**
インボイス制度の請求書では、端数処理は「税率ごとに請求書1枚につき1回」が原則。品目ごとに毎回丸めるのはNGとされています。
端数の切捨て/四捨五入/切上げを選べる税込・税抜計算機 → [URL]
(詳細は国税庁の資料を確認してください)

**X-04 ビルドログ**
消費税の計算をJSで書いて気づいたこと。
0.1 + 0.2 が 0.30000000000000004 になるあれ、税計算で出ると地味に怖い。
整数(円)で扱って最後に丸める設計にしました。税計算ツールを作る人は先に決めておくと楽です。

**X-05 ツールの使い方 税込→税抜**
税込11,000円は税抜いくら?
10%なら 11,000 ÷ 1.10 = 10,000円(消費税1,000円)
8%(軽減税率)なら 11,000 ÷ 1.08 ≒ 10,185円
入力するだけで出ます → [URL]

**X-06 源泉の落とし穴**
請求書で「報酬+消費税」を区分して書いてあるなら、源泉徴収は消費税を除いた報酬額に対して行える、という取扱いがあります。
区分がないと税込合計で計算することになります。
請求書の書き方で手取りが変わるので、区分記載は大事です。(要:国税庁の確認)

**X-07 副業の基本**
副業の所得が年間20万円以下でも、住民税の申告は別に必要になる場合があります(所得税の確定申告が不要でも)。
自分のケースはお住まいの自治体/税務署で確認を。
※一般論で個別の判断ではありません。

**X-08 割引計算**
「30%引き」の価格を出すとき、元値 × 0.7 でOK。
「30%引き→さらに10%引き」は 0.7 × 0.9 = 0.63 で37%引き(40%引きではない)。

**X-09 増減率**

逆に100万円→80万円に減ったら -20%。
増減率は「どちらを基準にするか」で数字が変わります。計算ツールの例を載せました → [URL]

## B. X スレッド(21〜28)

**X-21 スレッド: 源泉徴収を5ツイートで**
1/ 報酬から源泉徴収される/する、の基本を5ツイートで。
2/ 対象は原稿料・デザイン料・講演料など一定の報酬。商品代や一般的な物販は対象外です。
3/ 税率は 100万円以下 10.21%、超えた部分 20.42%(復興特別所得税込み)。
4/ 例: 報酬 300,000円 → 源泉 30,630円(300,000×10.21%)→ 差引支払 269,370円。
5/ 自動計算ツール → [URL] ※個別判断は税理士/税務署へ。

**X-22 スレッド: インボイス端数処理**
1/ 請求書の消費税、端数をどう丸めるか問題。
2/ 原則: 税率ごとに請求書1枚で1回。品目ごとの丸めを足し上げるのは不可とされています。
3/ 例: 税抜 1,234円 ×3品 = 3,702円 → 10% = 370.2円 → 切捨てなら370円(1回)。
4/ 丸め方(切捨て/四捨五入/切上げ)は事業者が選べる、が一般的な理解。ただし継続して同じ方法を使うのが無難。
5/ 計算ツール → [URL] ※公式要件を必ず確認。

**X-23 スレッド: 作ってみた(ビルドログ)**
1/ 3日で無料計算サイトを作って公開した話。
2/ 技術: 静的HTML/CSS/JS、Cloudflare Pagesで配信、サーバー処理なし。
3/ 工夫: 金額は整数で扱い、最後に丸める。
4/ 迷い: 広告を入れるか→ 運営費のため入れる。ただし誤クリックを誘う配置はしない。
5/ 公開した → [URL] 感想ください。

**X-24 スレッド: 割引の罠**
1/ 割引の計算あるある。
2/ 「30%引き+10%引き」は40%引きではなく37%引き(0.7×0.9=0.63)。
3/ 値上げ→値下げも同じで、+10%の後に-10%でも元には戻らない(1.1×0.9=0.99)。
4/ ツール → [URL]

**X-25 スレッド: 副業の請求書テンプレ項目**
1/ 副業で初めて請求書を出す人へ、最低限の項目。
2/ 宛名、発行日、請求書番号、自分の名前(屋号)、連絡先。
3/ 内容と金額、消費税、源泉徴収がある場合は差引額。
4/ 振込先・支払期限。
5/ 計算は [URL] ツールで。※インボイス登録している場合は登録番号も。

**X-26 スレッド: 経費の按分入門**
1/ 自宅兼事務所の家賃や通信費は「按分」が必要な場合があります。
2/ 考え方: 事業で使った割合(面積比/時間比など)を合理的に決める。
3/ 例: 通信費10,000円×事業割合60% = 6,000円。
4/ 根拠(使用時間のメモなど)を残す。
5/ 按分ツール作成を検討中 → ご意見ください。

**X-27 スレッド: 確定申告前にやること**
1/ 年が明ける前に副業でやっておくこと5つ。
2/ 売上と入金の突合。
3/ 領収書・レシートの整理。
4/ 源泉徴収された額の確認(支払調書)。
5/ 会計ソフトの選定(後述)。※詳しくは国税庁/税理士へ。

**X-28 スレッド: 運営の透明性**
1/ このサイトの運営について正直に書きます。
2/ 個人運営、目的は広告収益とアフィリエイト。
3/ 広告・アフィリエイトには必ず表記します。
4/ 計算結果は目安。誤りは訂正履歴を公開します。
5/ 問い合わせはフォームから。[URL]/contact
