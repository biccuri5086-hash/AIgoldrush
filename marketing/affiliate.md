# アフィリエイト方針(申請先・設置場所・広告表記)

重要: 以下は「申請を検討する候補」。提携可否・報酬額・承認条件・禁止事項は各ASP/広告主ごとに変わるため、**必ず管理画面の最新の案件ページで確認する**(本書は報酬額を記載しない。調査でも会計ソフト案件の最新条件は第三者記事から確認できなかった)。

## 1. 申請先ASP(登録は無料)

| ASP | 目的 | メモ |
|---|---|---|
| A8.net | 最初に登録。案件数が多く、提携審査が比較的通りやすいとされる | 公式サイトを持ってから申請。サイトが無い/内容が薄いと提携却下されやすい。案件検索で「弥生」「freee」「マネーフォワード」「会計」「請求書」「ドメイン」「レンタルサーバー」を検索 |
| もしもアフィリエイト | Amazon/楽天の簡単リンクと、会計系案件の有無確認 | 書籍(確定申告本)紹介にも使える |
| afb(アフィb) | 会計・金融・ビジネス系案件の確認 | 案件有無を確認 |
| バリューコマース | 案件確認 | サイト審査あり |
| 各社の直接プログラム | 会計ソフト・ドメイン・サーバーの公式アフィリエイト | 公式サイトのフッター等に「アフィリエイト」「パートナー」の案内がある場合あり。ASP経由と直接のどちらが条件良いか比較 |

注意: 審査用に、AdSenseと同様に運営者情報・プライバシーポリシー・お問い合わせを整備してから申請する。

## 2. 案件カテゴリと優先度

1. 会計ソフト(クラウド): 弥生、freee、マネーフォワード クラウド など(個人事業主・副業向けの確定申告対応)。ツールの読者(請求書・源泉・消費税)と親和性が高い。最優先。
2. 請求書作成サービス: 会計ソフトに含まれる場合も多い。単体案件があれば。
3. ドメイン・サーバー: 自分のサイト運営の実体験として紹介できるものだけ。
4. 書籍: 確定申告・インボイスの解説本(Amazon アソシエイト/楽天)。
5. 保留: 金融商品(クレカ・ローン等)は規制と信頼性のリスクが高いので、慣れるまで扱わない。

紹介は「実際に使った/比較検討した上で正直に」。使っていないものを「使ってよかった」と書かない(ステマ・優良誤認の恐れ)。

## 3. 設置場所(読者の役に立つ場面でのみ)

| 場所 | 内容 | 避けること |
|---|---|---|
| 解説記事の末尾「次のステップ」 | 「帳簿をつける会計ソフトを探している方へ」+比較表+リンク | 計算結果の直下に押しボタンを置いて誤クリックさせる |
| 専用の比較ページ(/accounting-software/ 等) | 条件別(青色申告、請求書機能、料金体系)の選び方と各社リンク | 一社だけを過剰に推す、根拠のない順位付け |
| 源泉徴収ツールのページ下 | 「請求・帳簿の管理」への案内を小さく | ツールUIと紛らわしい見た目の広告 |
| サイドバー/ヘッダー | 置かない(AdSenseと混在して審査・UXに悪影響) | |

- AdSenseの広告とアフィリエイトバナーを近接させない。AdSenseの「広告をクリックさせる誘導」は禁止(「広告をクリックしてください」等の文言禁止、自分でクリック禁止)。
- アフィリエイトリンクには `rel="sponsored nofollow"` を付ける(Googleの推奨)。

## 4. 広告表記(ステマ規制・景品表示法 2023年10月施行)への対応

- 事業者から報酬を得て行う紹介は、広告であることが一般消費者に分かるようにする必要がある(「PR」「広告」「プロモーション」「アフィリエイト広告を含みます」等)。
- 実装ルール:
  1. 該当ページの**冒頭(スクロール前に見える位置)**に表記する。例: 「【PR】本ページはアフィリエイト広告(広告)を含みます。紹介リンクから申込があると当サイトに報酬が入ることがあります。」
  2. 広告リンクの直前/直近にも「PR」を表示。
  3. X/note/Zenn等の投稿は先頭に「PR」(文末や#PRだけの小さな表示は避ける)。
  4. 運営者情報かポリシーページに「広告・アフィリエイトについて」の方針を記載(報酬を受け取ること、評価の独立性)。
  5. 表記を消したり、薄い色・小さい文字にしない。
- 表現ルール:
  - 「最安」「No.1」「絶対」「必ず節税」など、根拠のない最上級・断定をしない。数値(料金・割引・無料期間)は公式の最新情報で確認し、確認日を記載。
  - 個人の感想を事実のように書かない。体験していないことを体験談にしない。
  - 広告主の規約(禁止表現、キャンペーン表示ルール、ブランド名での検索連動広告の禁止 等)を読み、守る。
- 記録: 提携承認日、案件ページの規約のスクリーンショット、記事に載せた日付を管理(トラブル時の説明用)。

## 5. 税務メモ(副業)
- アフィリエイト報酬・AdSense収益は雑所得または事業所得として申告対象になりうる。会社員の副業で、所得が一定額以下でも住民税の申告が必要な場合がある。詳細は launch-checklist.md の税務セクション参照。
