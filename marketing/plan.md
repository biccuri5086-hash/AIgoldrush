# 90日 Go-To-Market 計画 — かんたん計算ツール

対象: 個人事業主・副業者向け無料計算サイト(AdSense + アフィリエイト収益)
現状ツール: 消費税計算(tax.html) / 源泉徴収税額計算(withholding.html) / 割合・割引・増減率(percent.html)
予算: 広告 ¥50,000(使用条件は kpi.md)。基本はオーガニック(SEO + SNS)で戦う。

> 方針: 嘘・誇張・スパム・購入フォロワー・相互リンク集め・自作自演ブクマは一切しない。「役に立つ無料ツールを正直に出す」だけで積み上げる。
> 前提: 本計画の検索ボリューム等の数値は未計測。Search Console / Googleキーワードプランナー / Ubersuggest 無料枠で実測してから優先度を調整する(数値を断定しない)。

---

## 0. ポジショニング

- 一言: 「個人事業主・副業の"請求書まわり"の計算を、登録不要・入力データ非保存でその場で終わらせる」
- 差別化: (1) 端数処理(切捨て/四捨五入/切上げ)の選択、(2) 報酬の源泉徴収で 100万円超の20.42%に対応、(3) 計算根拠の式と注意書きを併記、(4) 軽い・広告が邪魔しない。
- NG表現: 「税務相談」「節税できる」「確実」。必ず「目安・最終確認は税務署/税理士」を明記。

### 優先順位(競合が強い汎用語は後回し)
1. ロングテール(源泉徴収 × 職種/金額、消費税 × 端数・インボイス)で先に拾う。
2. 汎用語(消費税 計算 等)は大手計算サイトが強い前提。90日で上位は狙わず、被リンクと実績が溜まってから。
3. 新規ツール候補(Day30以降、実測で判断): 日割り計算、時給⇔日給、青色申告の経費按分(家事按分)、インボイス登録要否の目安、副業の所得20万円ライン判定(目安)、請求書の合計計算。

### オンページ施策(site/ は別担当。要望として開発側に渡す)
- 各ツールページ下に「使い方 / 計算式 / よくある質問(FAQ) / 注意事項 / 更新日」を追加。FAQ は構造化データ(FAQPage)化を検討。
- title は「◯◯計算|税込・税抜を10%/8%で即計算【無料】」のようにKWを前方に。
- 内部リンク: ツール間で「関連ツール」を相互に張る。トップから各ツールへ。
- 法令・税率は根拠(国税庁ページ)へ発リンクし、更新日を記載(E-E-A-T、YMYL領域なので特に重要)。
- Core Web Vitals は静的サイトで良好に保つ(広告タグ追加後に再計測)。

## 2. 90日タイムライン

### Phase 1: Day 1–14 「公開と計測の土台」
- launch-checklist.md を完走(独自ドメイン、Cloudflare Pages、Search Console、sitemap、AdSense申請用ページ、GA4等)。
- X / note / Zenn / Qiita / はてなブックマーク用アカウント準備(運営者名義を統一、プロフィールにサイトURLと「個人運営の無料ツール」と明記)。
- 初期コンテンツ: 各ツールの解説記事を3本(サイト内 or note)。
- 投稿: X は毎日1投稿(posts.md の X-01〜)。note に「作った理由」記事1本。
- KPI: インデックス登録3〜10ページ、Search Console で表示回数が出始める。

### Phase 2: Day 15–45 「コンテンツ量産と告知」
- 週2本の解説記事(サイト内 /guide/ or note → サイトへ内部リンク)。
- Zenn/Qiita: 技術寄りの記事を各1〜2本(「消費税の端数処理をJSで正しく実装する」「浮動小数点誤差を避ける税計算」)。※実装の学びを正直に共有、ツールへの誘導は末尾に1回のみ。
- はてなブックマーク: 自分の記事を自分でブクマして煽らない。記事が良ければ自然に付く前提。Hatena ID で通常の1ブクマのみ(複数アカ禁止)。
- AdSense 申請(コンテンツ量・必須ページが揃ってから。launch-checklist 参照)。
- アフィリエイト: A8.net等に登録 → 承認後に該当記事へ設置(affiliate.md)。
- KPI: 週次で Search Console 表示回数 +20〜30% を目標(未達でも原因を分析する)。

### Phase 3: Day 46–75 「拡張と合法的な被リンク」
- 新ツール1〜2本追加(Search Console の「クエリ」から需要確認して決定)。
- 被リンク(正攻法のみ):
  - 無料ツール系ディレクトリ/まとめへ掲載申請(運営者が掲載を募集しているもののみ。例: Product Hunt 日本語圏、ツール紹介まとめ、個人開発者向けの「個人開発サービス紹介」コミュニティ)。
  - 個人開発者向けの場での紹介(Zenn の「個人開発」タグ、Qiita Advent 以外の通常記事、X の #個人開発 #buildinpublic)。
  - 税理士/フリーランス向けブログ・メディアへ「参考ツールとして紹介してもらえませんか」と丁寧に個別連絡(1通ずつ。テンプレ一斉送信・金銭授受なし)。
  - freee/マネフォ等の公式コミュニティやQ&Aで、質問に答える際に"役立つ場合のみ"ツールを紹介(宣伝目的と分かる形で。何度も貼らない)。
  - 国税庁などの公的リンクは「発リンク」して信頼性を示す(被リンクを要求しない)。
- 禁止: リンク購入、PBN、相互リンク集め、質問サイトへの大量投稿、コメントスパム、自作自演ブクマ、アカウント複数持ち。
- KPI: 参照ドメイン数 5〜10(正当なもののみ)。

### Phase 4: Day 76–90 「評価と意思決定」
- kpi.md の判断ルールで広告予算 ¥50,000 の使用可否を決定。
- 勝ちパターン(どのKW/記事/投稿が伸びたか)を2倍にする。伸びない施策は停止。
- 確定申告シーズン(1月〜3月)・インボイス・年末調整に向けた季節コンテンツを先出し。

## 5. 想定リスクと対応
- YMYL(税金)領域: 誤情報は信頼を毀損。公式ソース確認、更新日表示、免責明記。年度の税制改正時は即更新。
- AdSense 審査落ち: 「有用性の低いコンテンツ」「必須ページ不足」が典型。記事・説明文を増やして再申請。
- 大手に勝てない汎用KW: ロングテール+独自価値(端数選択・解説)で勝負。
- 収益が小さい: 初期は月数百〜数千円程度でもあり得る。数値を期待で語らない。
